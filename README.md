# Titanic Survival Prediction

Predicts whether a passenger survived the Titanic disaster using machine learning.

## Tech Stack
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

## What I Did
- Cleaned missing values (age, embarked) and dropped unused columns
- Performed EDA: survival by gender, class, and feature correlations
- Trained Logistic Regression and Random Forest models
- Evaluated using accuracy, classification report, and confusion matrix
